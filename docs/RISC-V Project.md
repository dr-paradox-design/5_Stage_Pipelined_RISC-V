# 5-Stage Pipelined RISC-V

## Project Overview

This project implements a 5-stage pipelined RISC-V processor.

## Pipeline Stages

1. IF — Instruction Fetch
2. ID — Instruction Decode
3. EX — Execute
4. MEM — Memory Access
5. WB — Write Back
